Find answers to the most common questions about 333 Shop — from what kinds of projects are accepted to how the ordering process works.

<AccordionGroup>
  <Accordion title="Who is SQ?">
    SQ is a solo freelance web developer who builds clean, modern, professional websites. Every project gets individual attention from start to finish — no outsourcing, no shortcuts.
  </Accordion>

  <Accordion title="What kinds of projects do you accept?">
    Landing pages, portfolios, business sites, UI fixes, responsive redesigns, and backend features. If you're not sure whether your project fits, open a ticket and describe it — SQ will let you know.
  </Accordion>

  <Accordion title="How do I place an order?">
    Click "Buy / Open Ticket" on sqservices.me, fill out the short form with your name, contact info, and project description, then submit. You'll see a ticket ID on screen right away.
  </Accordion>

  <Accordion title="How do I contact SQ?">
    Submit a ticket on the site and include your Discord handle or email address. SQ will reach out via whichever method you provide.
  </Accordion>

  <Accordion title="Is the code AI-generated?">
    Every line of code is hand-written by SQ. That means clean, semantic markup, intentional structure, and code that's actually maintainable — not the bloated, generic output you get from AI tools.
  </Accordion>

  <Accordion title="Do you work with existing websites?">
    Yes. If you have an existing site you need fixed, redesigned, or extended, open a ticket and describe what needs to change. Attach relevant links or files if you have them.
  </Accordion>
</AccordionGroup>
