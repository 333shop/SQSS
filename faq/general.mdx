Find answers to the most common questions about 333 Shop — from what kinds of projects are accepted to how the ordering process works.

<AccordionGroup>
  <Accordion title="Who is SQ?">
    SQ is a solo freelance web developer who builds clean, modern, professional websites. All code is hand-written — no AI-generated output.
  </Accordion>

  <Accordion title="What kinds of projects do you accept?">
    Landing pages, portfolios, business sites, UI fixes, responsive redesigns, and backend features. If you're not sure, open a ticket and describe it.
  </Accordion>

  <Accordion title="How do I place an order?">
    Click "Buy / Open Ticket" on sqservices.me, fill out the short form, and submit. You'll receive a ticket ID immediately.
  </Accordion>

  <Accordion title="How do I contact SQ?">
    Submit a ticket on the site with your Discord handle or email. SQ will reach out via the contact method you provide.
  </Accordion>

  <Accordion title="Is the code AI-generated?">
    No. Every line of code is written by hand by SQ. Clean, semantic, and maintainable.
  </Accordion>

  <Accordion title="Do you work with existing websites?">
    Yes. If you have an existing site you need fixed, redesigned, or extended, open a ticket and attach or describe the relevant details.
  </Accordion>
</AccordionGroup>
